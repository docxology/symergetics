## Basic Usage

Complete, independently runnable Python blocks for rational arithmetic,
coordinate conversion, exact tetrahedral volume and live centroid comparison
are maintained in the [cookbook](../api-cookbook-recipes.md). The
[API reference](../api/index.md) is authoritative for signatures, units and
return types; examples should not duplicate a second inconsistent contract.

## Demo entry points

Actual scripts live in [`../../examples/`](../../examples/), not in this docs
folder. Run from the checkout in a scientific Python 3.13 environment:

```bash
uv sync --python 3.13 --extra scientific
MPLBACKEND=Agg uv run --python 3.13 --extra scientific python examples/symergetics_core_demo.py
```

| Script | Focus |
|---|---|
| [symergetics_core_demo.py](../../examples/symergetics_core_demo.py) | Core scalar, coordinate and geometric operations |
| [coordinate_systems_demo.py](../../examples/coordinate_systems_demo.py) | Coordinates, metrics and conversions |
| [number_theory_demo.py](../../examples/number_theory_demo.py) | Primorial and Scheherazade arithmetic |
| [mathematical_patterns_demo.py](../../examples/mathematical_patterns_demo.py) | Finite pattern analysis |
| [geometric_mnemonics_demo.py](../../examples/geometric_mnemonics_demo.py) | Geometric number associations and memory aids |
| [integration_demo.py](../../examples/integration_demo.py) | Combined package workflows |
| [visualization_demo.py](../../examples/visualization_demo.py) | Geometry, number and mathematical plots |
| [png_visualization_demo.py](../../examples/png_visualization_demo.py) | Raster-oriented plotting |
| [organized_output_demo.py](../../examples/organized_output_demo.py) | Configured output organization |
| [comprehensive_visualizations_demo.py](../../examples/comprehensive_visualizations_demo.py) | Advanced dashboards and modular scientific abstracts |
| [suite_interoperability.py](../../examples/suite_interoperability.py) | Real cross-project coordinate, metric, volume and lattice comparison |

Demos may create files under repository `output/`; do not run them over existing
user artifacts just to inspect a page. These are entry points, not recorded
successful runs or an exhaustive set of scientific applications. The suite
example additionally needs sibling checkouts and native/browser-language tools;
see [suite prerequisites](../synergetics-suite.md).

## Orchestrated Examples

```bash
MPLBACKEND=Agg uv run --python 3.13 --extra scientific python run.py --examples-only
```

`--examples-only` skips dependency installation and tests. The orchestrator
uses the selected interpreter, runs ordinary demos as real subprocesses,
records failures and writes `output/orchestration_results.json` plus logs.
Existing-file inventory entries are not proof that a file was generated by
this invocation. See [orchestration architecture](../architecture/index.md#orchestration-runpy).

## Scientific poster sections on unreleased main

`create_mega_graphical_abstract(..., section="overview")` is the focused default.
The demo also emits `geometry`, `arithmetic`, `patterns` and `all` sections;
`all` preserves seventeen computed topics. This selector is an unreleased-main
addition, not functionality promised by the immutable 1.3.0 release wheel.
All selections otherwise share the canonical filename, so the demo gives
the topic outputs separate filenames. See
[selection and metadata](../api/index.md#scientific-poster-sections-unreleased-main).

## Research Applications

A successful arithmetic or geometric demo does not validate active inference,
crystallographic fitting, biological modeling or cosmological claims. Those
applications require additional data, assumptions and validation beyond these
package scripts. See [research context](../research/index.md).
