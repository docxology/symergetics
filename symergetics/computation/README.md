# Computation: integer sequences and descriptive pattern analysis

- `primorials.py`: prime-bound `primorial(n)` (product of primes ≤ n),
  `scheherazade_power(n)` (`1001**n`), factorization and related sequences.
- `palindromes.py`: decimal palindrome, substring, repeated-pattern and symmetry
  analysis, plus Scheherazade experiments.
- `analysis.py`: `analyze_mathematical_patterns(number, analysis_depth=3)`,
  domain comparisons and report dictionaries.
- `geometric_mnemonics.py`: descriptive links to geometric ratios and integer
  ratio visualization (the plotting function requires matplotlib).

Use the [API reference](../../docs/api/index.md) for signatures. Integer and
rational calculations coexist with float scores, correlations and bounded
approximations. Pattern metrics and mnemonic associations are descriptive
algorithms, not proofs of universal physical, educational or fractal laws.
These modules do not impose a global output directory; callers and exporters
choose where reports/figures are written. Runnable workflows live in
[examples](../../examples/README.md).
