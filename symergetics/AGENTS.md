# symergetics/ — Agent Notes

The installable package (verified 2026-08-29):

- `core/` — constants, coordinates, numbers (foundational math)
- `computation/` — analysis, geometric mnemonics, palindromes, primorials
- `geometry/` — polyhedra, transformations
- `utils/` — conversion, mnemonics, reporting
- `visualization/` — modular plotting (matplotlib/plotly/ASCII backends)

Pure-Python, exact rational arithmetic emphasis. API docs: `../docs/api/`.
