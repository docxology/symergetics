# Paper Source Modules: Scope and Navigation

The twelve numbered Markdown files are the canonical editable manuscript.
Use the [ordered section map](../README.md#paper-structure); directory README
and agent notes are not paper sections.

The manuscript distinguishes exact implemented mathematics, approximation
boundaries, source review, historical test receipts and proposed applications.
Follow [writing guidance](../STYLE_GUIDE.md), link actual [API contracts](../../docs/api/index.md)
and preserve existing figure references without hand-editing generated artifacts.
